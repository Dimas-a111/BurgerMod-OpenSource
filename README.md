# 🍔 BurgerMod Open Source

**BurgerMod** is a powerful, customizable, and community-focused Discord moderation bot designed to make server management easier.

> 🛠️ **BurgerMod-OpenSource** — The open-source version of BurgerMod.

## ✨ Features

* 🛡️ Advanced moderation tools
* 🚨 Warning and punishment system
* 🔨 Ban, kick, timeout, and mute commands
* 🧹 Message moderation and cleanup
* 🎫 Support/ticket system
* 📋 Server logging
* ⚙️ Highly configurable settings
* 🤖 Automatic moderation features
* 📊 Server utilities and information commands
* 🔧 Open-source and customizable

## 📦 Installation

### Requirements

* [Python](https://www.python.org/)
* A Discord Bot Application
* Discord Bot Token
* Required Python dependencies

### 1. Clone the repository

```bash
git clone https://github.com/Dimas-a111/BurgerMod-OpenSource.git
cd BurgerMod-OpenSource
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure the bot

Create a `.env` file in the project directory:

```env
DISCORD_TOKEN=your_bot_token_here
```

**Never share your bot token or commit your `.env` file.**

### 4. Start BurgerMod

```bash
python main.py
```

## 📚 Commands

| Command       | Description                   |
| ------------- | ----------------------------- |
| `/help`       | Display available commands    |
| `/ban`        | Ban a member                  |
| `/kick`       | Kick a member                 |
| `/timeout`    | Timeout a member              |
| `/warn`       | Warn a member                 |
| `/clear`      | Delete messages               |
| `/userinfo`   | Show information about a user |
| `/serverinfo` | Show server information       |

> Command availability may change as BurgerMod is developed.
